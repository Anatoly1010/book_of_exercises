\zad[К]{12} В рамках метода Хюккеля энергетические уровни циклической системы из~$n$ центров (цикл Хюккеля) располагаются как вершины правильного $n$-угольника, вписанного в окружность и поставленного на одну из вершин. Однако для больших циклических $\pi$-систем возможно замыкание в цикл Мебиуса с~поворотом каждой $p$-орбитали. Энергетические уровни цикла Мебиуса располагаются как вершины такого же $n$-угольника, но поставленного на одну из его сторон. Схематически обе ситуации на примере бензола приведены на рисунке. Определите изменение полной электронной энергии циклической системы при трансформации из цикла Хюккеля в цикл Мебиуса для $n = 4k$ и $n = 4k + 2$ на~примере [8]аннулена и [10]аннулена. Укажите, какая форма для них предпочтительнее. При решении учтите, что резонансный интеграл $\beta_M$ для циклов Мебиуса пропорционален повороту $p$-орбиталей: $\beta_M = \beta \cos{\frac{\pi}{n}}$, где~$\beta$~\nobreakdash– резонансный интеграл для~циклов Хюккеля.
